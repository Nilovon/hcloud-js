```typescript
import { HCloudClient } from "@nilovonjs/hcloud-js";

const client = new HCloudClient();
```

## `list(params?)`

`GET /locations`

```typescript
const { locations, meta } = await client.locations.list({ sort: "name:asc" });
```

| Parameter          | Description                              |
| ------------------ | ---------------------------------------- |
| `name`             | Exact name                               |
| `sort`             | `id`, `name`, each with `:asc` / `:desc` |
| `page`, `per_page` | Pagination                               |

Pagination helpers: `listAll()`, `iterate()`, `iteratePages()`, `first()`.

```typescript
const all = await client.locations.listAll();
const eu = all.filter((location) => location.network_zone === "eu-central");
```

## `get(id)`

`GET /locations/{id}` - takes the numeric ID. Use `getByName()` to look up a name.

```typescript
const { location } = await client.locations.get(1);
console.log(location.name, location.city, location.country, location.network_zone);
```

## `getByName(name)`

Returns the location or `undefined`.

```typescript
const location = await client.locations.getByName("fsn1");
```
