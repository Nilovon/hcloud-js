---
title: ISOs
description: List the ISO images that can be attached to servers
---

```typescript
import { HCloudClient } from "@nilovonjs/hcloud-js";

const client = new HCloudClient();
```

Attach an ISO with `client.servers.attachISO()`.

## `list(params?)`

`GET /isos`

```typescript
const { isos, meta } = await client.isos.list({
  architecture: "arm",
  include_architecture_wildcard: true,
});
```

| Parameter | Description |
| --- | --- |
| `name` | Exact name |
| `architecture` | `x86`, `arm` - one or many |
| `include_architecture_wildcard` | Also return custom ISOs, which have no architecture, when filtering by `architecture` |
| `page`, `per_page` | Pagination |

Pagination helpers: `listAll()`, `iterate()`, `iteratePages()`, `first()`.

```typescript
const all = await client.isos.listAll();
```

## `get(id)`

`GET /isos/{id}`

```typescript
const { iso } = await client.isos.get(4711);
console.log(iso.name, iso.type, iso.architecture, iso.deprecation?.unavailable_after);
```

`iso.name` and `iso.architecture` are `null` for custom (`private`) ISOs. `iso.deprecation` is
`null` unless the ISO is deprecated; the former `iso.deprecated` timestamp is deprecated.

## `getByName(name)`

Returns the ISO or `undefined`.

```typescript
const iso = await client.isos.getByName("FreeBSD-11.0-RELEASE-amd64-dvd1");
```
