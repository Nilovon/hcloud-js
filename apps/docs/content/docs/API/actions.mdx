---
title: Actions
description: Track asynchronous operations and wait for them to finish
---

Actions represent asynchronous operations. Almost every mutating call returns
one. For a guided introduction see [Waiting for Actions](/docs/actions).

```typescript
import { HCloudClient } from "@nilovonjs/hcloud-js";

const client = new HCloudClient();
```

## The action object

```typescript
interface Action {
  id: number;
  command: string;                          // e.g. "start_server"
  status: "running" | "success" | "error";
  progress: number;                         // 0-100
  started: string;                          // ISO 8601
  finished: string | null;
  resources: { id: number; type: string }[];
  error?: { code: string; message: string } | null;
}
```

## `get(id)`

`GET /actions/{id}`

```typescript
const { action } = await client.actions.get(12345);
console.log(action.status, action.progress);
```

## `list(params?)`

`GET /actions`

The global endpoint only returns the actions whose IDs you pass. To browse
actions, use the `actions` sub-client of a resource (see below).

```typescript
const { actions } = await client.actions.list({ id: [1, 2, 3] });
```

| Parameter | Description |
| --- | --- |
| `id` | One or more action IDs |
| `status` | `"running"`, `"success"`, `"error"` (one or more) |
| `sort` | `id`, `command`, `status`, `started`, `finished`, each with `:asc` / `:desc` |
| `page`, `per_page` | Pagination |

## `waitFor(action, options?)`

Polls until the action has finished and returns it. Accepts an action, an ID
or a response containing an `action`.

```typescript
const action = await client.actions.waitFor(await client.servers.powerOn(42));
```

Throws `HCloudActionError` if the action fails and `HCloudActionTimeoutError`
if it does not finish in time.

## `waitForAll(actions, options?)`

Waits for several actions, polling them together in one request per poll.
Accepts an array of actions or IDs, or a response containing `action`,
`actions` and/or `next_actions`. Returns the finished actions in input order.

```typescript
const created = await client.servers.create({ name: "web-1", server_type: "cx22", image: "ubuntu-24.04" });
const finished = await client.actions.waitForAll(created);
```

### Wait options

| Option | Default | Description |
| --- | --- | --- |
| `pollInterval` | backoff from 500ms to 5s | Milliseconds or `(attempt) => ms` |
| `timeout` | `300000` | Maximum time to wait in milliseconds |
| `throwOnError` | `true` | Throw when an action fails |
| `onProgress` | - | `(action) => void`, called after every poll |
| `signal` | - | `AbortSignal` to stop waiting |

## Resource action clients

Every resource with actions exposes the same client scoped to its resource
type: `client.servers.actions`, `client.volumes.actions`,
`client.networks.actions`, `client.firewalls.actions`,
`client.floatingIPs.actions`, `client.primaryIPs.actions`,
`client.loadBalancers.actions`, `client.certificates.actions`,
`client.images.actions`, `client.dns.actions` and `client.storageBoxes.actions`.

```typescript
// GET /servers/actions
const { actions } = await client.servers.actions.list({ status: "running", sort: "started:desc" });

// GET /servers/actions/{id}
const { action } = await client.servers.actions.get(12345);

// Pagination helpers
const all = await client.volumes.actions.listAll({ status: "error" });
for await (const action of client.networks.actions.iterate()) {
  console.log(action.command);
}
```

<Callout>
  Storage Box actions live on a different API host. Always wait for them with
  `client.storageBoxes.actions.waitFor(...)`.
</Callout>
