---
title: SSH Keys
description: Manage SSH public keys that can be injected into servers
---

```typescript
import { HCloudClient } from "@nilovonjs/hcloud-js";

const client = new HCloudClient();
```

## `list(params?)`

`GET /ssh_keys`

```typescript
const { ssh_keys, meta } = await client.sshKeys.list({
  label_selector: "team=platform",
  sort: "name:asc",
});
```

| Parameter | Description |
| --- | --- |
| `name` | Exact name |
| `fingerprint` | Exact fingerprint |
| `label_selector` | [Label selector](/docs/pagination#label-selectors) |
| `sort` | `id`, `name`, each with `:asc` / `:desc` |
| `page`, `per_page` | Pagination |

Pagination helpers: `listAll()`, `iterate()`, `iteratePages()`, `first()`.

```typescript
const all = await client.sshKeys.listAll();
```

## `get(id)`

`GET /ssh_keys/{id}`

```typescript
const { ssh_key } = await client.sshKeys.get(12345);
```

## `getByName(name)`

Returns the SSH key or `undefined`.

```typescript
const key = await client.sshKeys.getByName("laptop");
```

## `getByFingerprint(fingerprint)`

Returns the SSH key or `undefined`.

```typescript
const key = await client.sshKeys.getByFingerprint("b7:2f:30:a0:2f:6c:58:6c:21:04:58:61:ba:06:3b:2f");
```

## `create(params)`

`POST /ssh_keys`

```typescript
const { ssh_key } = await client.sshKeys.create({
  name: "laptop",
  public_key: "ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAA...",
  labels: { team: "platform" },
});
```

## `update(id, params)`

`PUT /ssh_keys/{id}`

```typescript
const { ssh_key } = await client.sshKeys.update(12345, {
  name: "laptop-2026",
  labels: { team: "platform" },
});
```

## `delete(id)`

`DELETE /ssh_keys/{id}` - resolves without a value.

```typescript
await client.sshKeys.delete(12345);
```
