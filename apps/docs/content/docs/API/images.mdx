---
title: Images
description: System images, apps, snapshots and backups
---

```typescript
import { HCloudClient } from "@nilovonjs/hcloud-js";

const client = new HCloudClient();
```

Snapshots are created with `client.servers.createImage()`.

## `list(params?)`

`GET /images`

```typescript
const { images, meta } = await client.images.list({
  type: "snapshot",
  label_selector: "environment=production",
  sort: "created:desc",
});
```

| Parameter            | Description                                                     |
| -------------------- | --------------------------------------------------------------- |
| `name`               | Exact name. System images share their name across architectures |
| `type`               | `system`, `app`, `snapshot`, `backup` - one or many             |
| `status`             | `available`, `creating`, `unavailable` - one or many            |
| `architecture`       | `x86`, `arm` - one or many                                      |
| `bound_to`           | Server IDs, for images of type `backup` - one or many           |
| `include_deprecated` | Include deprecated images. Default: `false`                     |
| `label_selector`     | [Label selector](/docs/pagination#label-selectors)              |
| `sort`               | `id`, `name`, `created`, each with `:asc` / `:desc`             |
| `page`, `per_page`   | Pagination                                                      |

Pagination helpers: `listAll()`, `iterate()`, `iteratePages()`, `first()`.

```typescript
const snapshots = await client.images.listAll({ type: "snapshot" });
const newest = await client.images.first({ type: "snapshot", sort: "created:desc" });
```

## `get(id)`

`GET /images/{id}`

```typescript
const { image } = await client.images.get(45557056);
console.log(image.name, image.architecture, image.deprecation?.unavailable_after);
```

`image.deprecation` is `null` unless the image is deprecated. The former `image.deprecated`
timestamp was removed from the API by Hetzner.

## `getByNameAndArchitecture(name, architecture, params?)`

Returns the image or `undefined`. Prefer this over `getByName()`: system images exist once per
architecture under the same name.

```typescript
const image = await client.images.getByNameAndArchitecture("ubuntu-24.04", "arm");

// Also find deprecated images
const old = await client.images.getByNameAndArchitecture("debian-11", "x86", {
  include_deprecated: true,
});
```

## `getByName(name)`

Returns the first image with this name or `undefined`.

```typescript
const image = await client.images.getByName("ubuntu-24.04");
```

## `update(id, params)`

`PUT /images/{id}` - updates `description` and/or `labels`. `type: "snapshot"` converts a backup
into a snapshot. Only for snapshots and backups.

```typescript
const { image } = await client.images.update(429564329, {
  description: "Before the upgrade",
  labels: { environment: "production" },
});
```

## `delete(id)`

`DELETE /images/{id}` - resolves without a value. Only for snapshots and backups.

```typescript
await client.images.delete(429564329);
```

## `changeProtection(id, params)`

`POST /images/{id}/actions/change_protection` - returns `{ action }`. Only for snapshots.

```typescript
const { action } = await client.images.changeProtection(429564329, { delete: true });
await client.actions.waitFor(action);
```

## `listActions(id, params?)`

`GET /images/{id}/actions`

```typescript
const { actions } = await client.images.listActions(429564329, {
  status: "running",
  sort: "started:desc",
});
```

## `getAction(id, actionId)`

`GET /images/{id}/actions/{action_id}`

```typescript
const { action } = await client.images.getAction(429564329, 13);
```

## `actions`

Actions of all images: `GET /images/actions` and `GET /images/actions/{id}`. Has the same helpers
as [`client.actions`](/docs/API/actions).

```typescript
const { actions } = await client.images.actions.list({ status: "running" });
const { action } = await client.images.actions.get(13);
const all = await client.images.actions.listAll({ status: "error" });
```
