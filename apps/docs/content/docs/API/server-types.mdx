---
title: Server Types
description: List the server types and the locations they are available in
---

```typescript
import { HCloudClient } from "@nilovonjs/hcloud-js";

const client = new HCloudClient();
```

## `list(params?)`

`GET /server_types`

```typescript
const { server_types, meta } = await client.serverTypes.list();
```

| Parameter | Description |
| --- | --- |
| `name` | Exact name |
| `page`, `per_page` | Pagination |

Pagination helpers: `listAll()`, `iterate()`, `iteratePages()`, `first()`.

```typescript
const all = await client.serverTypes.listAll();
const arm = all.filter((serverType) => serverType.architecture === "arm");
```

## `get(id)`

`GET /server_types/{id}` - takes the numeric ID. Use `getByName()` to look up a name.

```typescript
const { server_type } = await client.serverTypes.get(22);
console.log(server_type.cores, server_type.memory, server_type.disk);
```

## `getByName(name)`

Returns the server type or `undefined`.

```typescript
const serverType = await client.serverTypes.getByName("cpx22");
```

## Per-location information

Availability and deprecation are reported per location in `locations[]`.

```typescript
const serverType = await client.serverTypes.getByName("cpx22");

for (const location of serverType?.locations ?? []) {
  console.log(location.name, {
    available: location.available,
    recommended: location.recommended,
    deprecated: location.deprecation !== null,
    unavailableAfter: location.deprecation?.unavailable_after,
  });
}
```

| Field | Description |
| --- | --- |
| `locations[].id`, `locations[].name` | The location |
| `locations[].available` | Servers of this type can currently be created in the location |
| `locations[].recommended` | The type is currently recommended in the location |
| `locations[].deprecation` | `{ announced, unavailable_after }`, or `null` if not deprecated |
| `prices[]` | `location`, `price_hourly`, `price_monthly`, `included_traffic`, `price_per_tb_traffic` |
| `category` | Category of the type, e.g. `Shared vCPU` |

The top-level `deprecated`, `deprecation` and `included_traffic` fields are deprecated by Hetzner
and may be missing. Use `locations[].deprecation` and `prices[].included_traffic` instead.
