title: Pricing
description: Get the prices of all resources

```typescript
import { HCloudClient } from "@nilovonjs/hcloud-js";

const client = new HCloudClient();
```

## `getAll()`

`GET /pricing`

```typescript
const { pricing } = await client.pricing.getAll();
console.log(pricing.currency, pricing.vat_rate);
```

Prices are objects with a `net` and a `gross` amount, encoded as decimal strings.

| Field | Description |
| --- | --- |
| `currency`, `vat_rate` | Currency and VAT rate of the project owner |
| `server_types[]` | `id`, `name` and `prices[]` per location |
| `load_balancer_types[]` | `id`, `name` and `prices[]` per location |
| `primary_ips[]` | `type` and `prices[]` per location |
| `floating_ips[]` | `type` and `prices[]` per location |
| `image` | `price_per_gb_month` |
| `volume` | `price_per_gb_month` |
| `server_backup` | `percentage` of the server price |

`prices[]` entries contain `location` and, depending on the resource, `price_hourly`,
`price_monthly`, `included_traffic` and `price_per_tb_traffic`. All fields except `currency` and
`vat_rate` may be missing.

```typescript
const { pricing } = await client.pricing.getAll();

const cpx22 = pricing.server_types?.find((serverType) => serverType.name === "cpx22");
const inFalkenstein = cpx22?.prices.find((price) => price.location === "fsn1");
console.log(inFalkenstein?.price_monthly?.gross, pricing.currency);
```
