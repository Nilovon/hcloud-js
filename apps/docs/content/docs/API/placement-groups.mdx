---
title: Placement Groups
description: Control how servers are distributed across physical hosts
---

```typescript
import { HCloudClient } from "@nilovonjs/hcloud-js";

const client = new HCloudClient();
```

## `list(params?)`

`GET /placement_groups`

```typescript
const { placement_groups, meta } = await client.placementGroups.list({
  label_selector: "environment=production",
  sort: "name:asc",
});
```

| Parameter | Description |
| --- | --- |
| `name` | Exact name |
| `label_selector` | [Label selector](/docs/pagination#label-selectors) |
| `type` | `spread` |
| `sort` | `id`, `name`, `created`, each with `:asc` / `:desc` |
| `page`, `per_page` | Pagination |

Pagination helpers: `listAll()`, `iterate()`, `iteratePages()`, `first()`.

```typescript
const all = await client.placementGroups.listAll();
```

## `get(id)`

`GET /placement_groups/{id}`

```typescript
const { placement_group } = await client.placementGroups.get(897);
console.log(placement_group.servers); // IDs of the assigned servers
```

## `getByName(name)`

Returns the placement group or `undefined`.

```typescript
const group = await client.placementGroups.getByName("web");
```

## `create(params)`

`POST /placement_groups`

```typescript
const { placement_group } = await client.placementGroups.create({
  name: "web",
  type: "spread",
  labels: { environment: "production" },
});
```

The response may contain an `action`. If it does, wait for it with
`await client.actions.waitFor(action)`.

Assign servers with `placement_group` in `client.servers.create()` or with
`client.servers.addToPlacementGroup()`.

## `update(id, params)`

`PUT /placement_groups/{id}` - updates `name` and/or `labels`.

```typescript
const { placement_group } = await client.placementGroups.update(897, {
  name: "web-eu",
  labels: { environment: "production" },
});
```

## `delete(id)`

`DELETE /placement_groups/{id}` - resolves without a value.

```typescript
await client.placementGroups.delete(897);
```
