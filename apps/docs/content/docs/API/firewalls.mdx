# Firewalls API

`client.firewalls` manages [Firewalls](https://docs.hetzner.cloud/reference/cloud#firewalls): their
rules and the servers or label selectors they are applied to.

```typescript
import { HCloudClient } from "@nilovonjs/hcloud-js";

const client = new HCloudClient();
```

- Every method takes an optional trailing `options` argument (`signal`, `timeout`, `headers`, `retry`).
- `create()`, `setRules()`, `applyToResources()` and `removeFromResources()` return a list of
  `actions`. Wait for them with `client.actions.waitForAll()`.
- `firewall.rules` is a flat list; every rule has a `direction` (`"in"` or `"out"`).

| Method                                                                               | Endpoint                                                |
| ------------------------------------------------------------------------------------ | ------------------------------------------------------- |
| `list(params?)`                                                                      | `GET /firewalls`                                        |
| `iterate(params?)` / `iteratePages(params?)` / `listAll(params?)` / `first(params?)` | `GET /firewalls` (paginated for you)                    |
| `getByName(name)`                                                                    | `GET /firewalls?name=...`                               |
| `get(id)`                                                                            | `GET /firewalls/{id}`                                   |
| `create(params)`                                                                     | `POST /firewalls`                                       |
| `update(id, params)`                                                                 | `PUT /firewalls/{id}`                                   |
| `delete(id)`                                                                         | `DELETE /firewalls/{id}`                                |
| `setRules(id, params)`                                                               | `POST /firewalls/{id}/actions/set_rules`                |
| `applyToResources(id, params)`                                                       | `POST /firewalls/{id}/actions/apply_to_resources`       |
| `removeFromResources(id, params)`                                                    | `POST /firewalls/{id}/actions/remove_from_resources`    |
| `listActions(id, params?)`                                                           | `GET /firewalls/{id}/actions`                           |
| `getAction(id, actionId)`                                                            | `GET /firewalls/{id}/actions/{action_id}`               |
| `actions.list(params?)` / `actions.get(id)`                                          | `GET /firewalls/actions`, `GET /firewalls/actions/{id}` |

## Firewalls

### List firewalls

Returns one page of firewalls. Filters: `name`, `label_selector`, `sort` (`id`, `name`, `created`),
`page`, `per_page`.

```typescript
const { firewalls, meta } = await client.firewalls.list({
  label_selector: "environment=production",
  sort: "name:asc",
});
```

### All firewalls

`iterate()`, `iteratePages()`, `listAll()` and `first()` follow the pagination for you and accept
the same filters as `list()`.

```typescript
for await (const firewall of client.firewalls.iterate()) {
  console.log(firewall.name, firewall.rules.length);
}

const all = await client.firewalls.listAll();
const newest = await client.firewalls.first({ sort: "created:desc" }); // Firewall | undefined
```

### Get a firewall

```typescript
const { firewall } = await client.firewalls.get(12345);
console.log(firewall.rules, firewall.applied_to);

// By exact name; resolves to `undefined` if there is none
const byName = await client.firewalls.getByName("web");
```

### Create a firewall

Only `name` is required. `rules` and `apply_to` are optional; the returned `actions` track setting
the rules and applying the firewall.

```typescript
const created = await client.firewalls.create({
  name: "web",
  labels: { environment: "production" },
  rules: [
    { direction: "in", protocol: "tcp", port: "443", source_ips: ["0.0.0.0/0", "::/0"] },
    { direction: "in", protocol: "icmp", source_ips: ["0.0.0.0/0", "::/0"] },
  ],
  apply_to: [{ type: "label_selector", label_selector: { selector: "role=web" } }],
});

await client.actions.waitForAll(created);
console.log(created.firewall.id);
```

### Update a firewall

Changes the `name` and/or `labels`. Use `setRules()` to change the rules.

```typescript
const { firewall } = await client.firewalls.update(12345, {
  name: "new-name",
  labels: { environment: "production" },
});
```

### Delete a firewall

The firewall must not be applied to any resource anymore. Resolves without a value.

```typescript
await client.firewalls.delete(12345);
```

## Rules

| Field             | Description                                                                                       |
| ----------------- | ------------------------------------------------------------------------------------------------- |
| `direction`       | `"in"` or `"out"`                                                                                 |
| `protocol`        | `"tcp"`, `"udp"`, `"icmp"`, `"esp"` or `"gre"`                                                    |
| `port`            | Port (`"80"`) or port range (`"1024-5000"`). Required for `tcp` and `udp`, not allowed otherwise. |
| `source_ips`      | CIDRs traffic is allowed from, for rules with direction `in`                                      |
| `destination_ips` | CIDRs traffic is allowed to, for rules with direction `out`                                       |
| `description`     | Optional description                                                                              |

### Set rules

Replaces **all** rules of the firewall. Pass an empty array to remove all rules.

```typescript
const { actions } = await client.firewalls.setRules(12345, {
  rules: [
    {
      direction: "in",
      protocol: "tcp",
      port: "80",
      source_ips: ["0.0.0.0/0", "::/0"],
      description: "Allow HTTP from everywhere",
    },
    { direction: "out", protocol: "udp", port: "53", destination_ips: ["0.0.0.0/0", "::/0"] },
  ],
});
await client.actions.waitForAll(actions);
```

Rules returned by the API can be passed back as they are, so adding a rule is a spread:

```typescript
const { firewall } = await client.firewalls.get(12345);

await client.firewalls.setRules(12345, {
  rules: [
    ...firewall.rules,
    { direction: "in", protocol: "tcp", port: "22", source_ips: ["203.0.113.7/32"] },
  ],
});
```

## Resources

A firewall is applied to a server (`{ type: "server", server: { id } }`) or to all servers
matching a label selector (`{ type: "label_selector", label_selector: { selector } }`).

### Apply to resources

```typescript
const { actions } = await client.firewalls.applyToResources(12345, {
  apply_to: [
    { type: "server", server: { id: 42 } },
    { type: "label_selector", label_selector: { selector: "role=web" } },
  ],
});
await client.actions.waitForAll(actions);
```

### Remove from resources

```typescript
const { actions } = await client.firewalls.removeFromResources(12345, {
  remove_from: [{ type: "server", server: { id: 42 } }],
});
await client.actions.waitForAll(actions);
```

Entries of `firewall.applied_to` can be passed back as they are, e.g. to detach a firewall
completely before deleting it:

```typescript
const { firewall } = await client.firewalls.get(12345);

if (firewall.applied_to.length > 0) {
  await client.actions.waitForAll(
    await client.firewalls.removeFromResources(12345, { remove_from: firewall.applied_to }),
  );
}
await client.firewalls.delete(12345);
```

## Actions

```typescript
// Actions of one firewall
const { actions } = await client.firewalls.listActions(12345, {
  status: "running",
  sort: "started:desc",
});
const { action } = await client.firewalls.getAction(12345, 67890);

// Actions of all firewalls
const running = await client.firewalls.actions.list({ status: "running" });
const single = await client.firewalls.actions.get(67890);
```

### Waiting for actions

`waitFor()` waits for a single action (or action ID), `waitForAll()` for a list of actions or a
response containing `actions`.

```typescript
const { actions } = await client.firewalls.setRules(12345, { rules: [] });

const [first] = actions;
if (first) await client.actions.waitFor(first);

await client.actions.waitForAll(actions);
```

## Types

```typescript
interface Firewall {
  id: number;
  name: string;
  labels: Record<string, string>;
  created: string;
  rules: FirewallRule[];
  applied_to: FirewallAppliedToResource[];
}

interface FirewallRule {
  direction: "in" | "out";
  protocol: "tcp" | "udp" | "icmp" | "esp" | "gre";
  source_ips: string[];
  destination_ips: string[];
  port: string | null;
  description: string | null;
}

interface FirewallAppliedToResource {
  type: "server" | "label_selector";
  server?: { id: number } | null;
  label_selector?: { selector: string } | null;
  // Servers the firewall is effectively applied to through a label selector
  applied_to_resources?: Array<{ type: string; server?: { id: number } | null }> | null;
}

// Request shapes (`FirewallRule` / `FirewallAppliedToResource` objects are accepted as well)
interface FirewallRuleInput {
  direction: "in" | "out";
  protocol: "tcp" | "udp" | "icmp" | "esp" | "gre";
  source_ips?: string[];
  destination_ips?: string[];
  port?: string | null;
  description?: string | null;
}

interface FirewallResourceInput {
  type: "server" | "label_selector";
  server?: { id: number } | null;
  label_selector?: { selector: string } | null;
}
```
