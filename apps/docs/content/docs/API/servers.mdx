# Servers API

`client.servers` manages [servers](https://docs.hetzner.cloud/reference/cloud#servers): virtual
machines that can be provisioned.

```typescript
import { HCloudClient } from "@nilovonjs/hcloud-js";

const client = new HCloudClient();
```

- Raw endpoint methods return the API envelope (`{ server }`, `{ action }`, ...), convenience
  methods (`getByName`, `first`, `listAll`, `waitForStatus`) return the bare `Server`.
- Every method takes an optional trailing `options` argument (`signal`, `timeout`, `headers`, `retry`).
- Most mutating calls return an `action`. Wait for it with `client.actions.waitFor()`.

## Servers

### List servers

Returns one page of servers. Filters: `name`, `label_selector`, `status`, `sort`
(`id`, `name`, `created`), `page`, `per_page`.

```typescript
const { servers, meta } = await client.servers.list({
  status: ["running", "off"],
  label_selector: "environment=production",
  sort: "name:asc",
});
```

### All servers

The inherited helpers follow the pagination for you and accept the same filters.

```typescript
// Everything in one array
const all = await client.servers.listAll({ status: "running" });

// Item by item, fetching pages lazily
for await (const server of client.servers.iterate({ label_selector: "environment=production" })) {
  console.log(server.name, server.public_net.ipv4?.ip);
}

// Page by page
for await (const page of client.servers.iteratePages({ per_page: 25 })) {
  console.log(page.servers.length, page.meta?.pagination?.total_entries);
}

// First match or undefined
const newest = await client.servers.first({ sort: "created:desc" });
```

### Get a server

```typescript
const { server } = await client.servers.get(12345);
console.log(server.status, server.location.name, server.server_type.name);

// By name: the server or undefined
const web = await client.servers.getByName("web-1");
```

### Create a server

`name`, `server_type` and `image` are required. Server type, image, location and SSH keys are
referenced by ID or name. `root_password` is `null` if SSH keys were passed.

```typescript
const { server, action, next_actions, root_password } = await client.servers.create({
  name: "web-1",
  server_type: "cx22",
  image: "ubuntu-24.04",
  location: "nbg1",
  ssh_keys: ["my-ssh-key"],
  networks: [4711],
  firewalls: [{ firewall: 38 }],
  volumes: [1234],
  automount: true,
  placement_group: 897,
  public_net: { enable_ipv4: true, enable_ipv6: false },
  user_data: "#cloud-config\npackages:\n  - nginx\n",
  labels: { environment: "production" },
  start_after_create: true,
});

// The server is not ready yet: wait for `action` and `next_actions`
await client.actions.waitForAll({ action, next_actions });
```

### Create a server and wait

`createAndWait()` creates the server, waits for `action` and all `next_actions` and returns the
create response with the freshly fetched server and the finished actions. The optional second
argument takes the same polling options as `client.actions.waitFor()`.

```typescript
const { server, root_password } = await client.servers.createAndWait(
  { name: "web-1", server_type: "cx22", image: "ubuntu-24.04" },
  { timeout: 120_000, onProgress: (action) => console.log(action.command, action.progress) },
);
console.log(server.status); // "running"
```

It throws `HCloudActionError` if an action fails and `HCloudActionTimeoutError` on timeout.

### Update a server

Updates the name and/or labels.

```typescript
const { server } = await client.servers.update(12345, {
  name: "web-2",
  labels: { environment: "staging" },
});
```

### Delete a server

```typescript
const { action } = await client.servers.delete(12345);
await client.actions.waitFor(action);
```

### Wait for a status

`waitForStatus()` polls the server until it has the given status (or one of several) and returns
it. Options: `pollInterval` (default `1000` ms), `timeout` (default `300000` ms), `signal`.
On timeout it throws an `HCloudError` with the code `WAIT_TIMEOUT`.

```typescript
// The shutdown action finishes once the ACPI request was sent, not once the server is off
await client.servers.shutdown(12345);
const server = await client.servers.waitForStatus(12345, "off", { timeout: 60_000 });
```

### Metrics

`type` is one or more of `"cpu"`, `"disk"`, `"network"`. `start` and `end` accept a `Date` or an
ISO 8601 string, `step` is the resolution in seconds.

```typescript
const { metrics } = await client.servers.getMetrics(12345, {
  type: ["cpu", "network"],
  start: new Date(Date.now() - 60 * 60 * 1000),
  end: new Date(),
  step: 60,
});

for (const [timestamp, value] of metrics.time_series.cpu?.values ?? []) {
  console.log(new Date(timestamp * 1000), value);
}
```

## Actions

Every method in this section returns `{ action }` unless noted otherwise.

```typescript
const { action } = await client.servers.powerOn(12345);
const finished = await client.actions.waitFor(action);

// or in one go
await client.actions.waitFor(await client.servers.reboot(12345));
```

### Action history

```typescript
// Actions of one server
const { actions } = await client.servers.listActions(12345, {
  status: "running",
  sort: "started:desc",
});
const { action } = await client.servers.getAction(12345, 67890);

// Actions of all servers
const running = await client.servers.actions.listAll({ status: "running" });
const { action: other } = await client.servers.actions.get(67890);
```

`client.servers.actions` also offers `waitFor()` and `waitForAll()`, which poll
`/servers/actions` instead of the global `/actions` endpoint.

### Power

```typescript
await client.servers.powerOn(12345); // start
await client.servers.shutdown(12345); // graceful shutdown (ACPI)
await client.servers.reboot(12345); // graceful reboot (ACPI)
await client.servers.reset(12345); // hard reset
await client.servers.powerOff(12345); // cut power, may lead to data loss
```

### Root password

Requires a running server with the qemu guest agent.

```typescript
const { action, root_password } = await client.servers.resetRootPassword(12345);
```

### Rescue mode

The server boots into the rescue system on the next reboot.

```typescript
const { action, root_password } = await client.servers.enableRescueMode(12345, {
  type: "linux64",
  ssh_keys: [2323], // SSH key IDs
});
await client.servers.reboot(12345);

await client.servers.disableRescueMode(12345);
```

### Images and rebuild

```typescript
// Snapshot (default) or backup. Returns the action and the image being created.
const { action, image } = await client.servers.createImage(12345, {
  type: "snapshot",
  description: "before-upgrade",
  labels: { reason: "upgrade" },
});
await client.actions.waitFor(action);

// Overwrite the disk with an image. `root_password` is null if the server has SSH keys.
const rebuilt = await client.servers.rebuild(12345, {
  image: "ubuntu-24.04",
  user_data: "#cloud-config\n",
});
console.log(rebuilt.root_password);
```

### Server type

The server must be powered off. `upgrade_disk: false` keeps the disk size, which allows
downgrading later.

```typescript
const { action } = await client.servers.changeType(12345, {
  server_type: "cx32",
  upgrade_disk: false,
});
```

### Protection

```typescript
await client.servers.changeProtection(12345, { delete: true, rebuild: true });
```

### Backups

The backup window is chosen by Hetzner and reported as `server.backup_window`.

```typescript
await client.servers.enableBackups(12345);
await client.servers.disableBackups(12345); // deletes all existing backups
```

### ISOs

```typescript
await client.servers.attachISO(12345, { iso: "FreeBSD-11.0-RELEASE-amd64-dvd1" });
await client.servers.detachISO(12345);
```

### Reverse DNS

```typescript
await client.servers.changeReverseDNS(12345, { ip: "1.2.3.4", dns_ptr: "web-1.example.com" });

// Reset to the default
await client.servers.changeReverseDNS(12345, { ip: "1.2.3.4", dns_ptr: null });
```

### Console

Returns credentials for VNC over websocket. They are valid for a limited time only.

```typescript
const { wss_url, password } = await client.servers.requestConsole(12345);
```

### Networks

```typescript
await client.servers.attachToNetwork(12345, {
  network: 4711,
  ip: "10.0.1.1", // optional
  alias_ips: ["10.0.1.2"], // optional
  ip_range: "10.0.1.0/24", // optional: subnet to attach to
});

await client.servers.changeAliasIPs(12345, { network: 4711, alias_ips: ["10.0.1.2", "10.0.1.3"] });

await client.servers.detachFromNetwork(12345, { network: 4711 });
```

### Placement groups

The server must be powered off to be added to a placement group.

```typescript
await client.servers.addToPlacementGroup(12345, { placement_group: 897 });
await client.servers.removeFromPlacementGroup(12345);
```

## The `Server` object

```typescript
import type { Server, ServerStatus } from "@nilovonjs/hcloud-js";
```

| Field | Type | Notes |
| --- | --- | --- |
| `id`, `name`, `created` | `number`, `string`, `string` | |
| `status` | `ServerStatus` | `running`, `initializing`, `starting`, `stopping`, `off`, `deleting`, `migrating`, `rebuilding`, `unknown` |
| `public_net` | `ServerPublicNet` | `ipv4` and `ipv6` are `null` if the server has none, `floating_ips` and `firewalls` hold IDs |
| `private_net` | `ServerPrivateNet[]` | `network` (ID), `ip`, `alias_ips`, `mac_address` |
| `server_type` | `ServerType` | |
| `location` | `Location` | |
| `datacenter` | `Datacenter \| undefined` | Deprecated: [removed from the API](https://docs.hetzner.cloud/changelog#2026-07-01-removing-datacenters), use `location` |
| `image` | `Image \| null` | `null` if the image was deleted |
| `iso` | `ISO \| null` | |
| `placement_group` | `PlacementGroup \| null \| undefined` | |
| `rescue_enabled`, `locked` | `boolean` | |
| `backup_window` | `string \| null` | e.g. `"22-02"`, `null` if backups are disabled |
| `outgoing_traffic`, `ingoing_traffic`, `included_traffic` | `number \| null` | Bytes in the current billing period |
| `primary_disk_size` | `number` | GB |
| `protection` | `ServerProtection` | `delete`, `rebuild` |
| `labels` | `Labels` | |
| `volumes` | `number[]` | IDs |
| `load_balancers` | `number[] \| undefined` | IDs |
