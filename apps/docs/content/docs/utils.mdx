Besides the client, the package exports a few standalone helpers.

## `labelSelector()`

Builds [label selector](https://docs.hetzner.cloud/reference/cloud#label-selector)
strings. All conditions must match.

```typescript
import { labelSelector } from "@nilovonjs/hcloud-js";

labelSelector({ env: "production" }); // "env=production"
labelSelector({ env: ["staging", "production"] }); // "env in (staging,production)"
labelSelector({ env: { not: "dev" } }); // "env!=dev"
labelSelector({ env: { notIn: ["dev", "test"] } }); // "env notin (dev,test)"
labelSelector({ managed: true, legacy: false }); // "managed,!legacy"
```

## `parseTimeSeries()`

Metrics endpoints return `[timestamp, "value"]` tuples. `parseTimeSeries()`
converts them into `Date`/`number` points:

```typescript
import { parseTimeSeries } from "@nilovonjs/hcloud-js";

const { metrics } = await client.servers.getMetrics(42, {
  type: "cpu",
  start: new Date(Date.now() - 60 * 60 * 1000),
  end: new Date(),
});

for (const point of parseTimeSeries(metrics.time_series).cpu ?? []) {
  console.log(point.timestamp.toISOString(), point.value);
}
```

## Type guards

Narrow resources by their state:

```typescript
import {
  isActionCompleted,
  isActionFailed,
  isActionRunning,
  isActionSuccessful,
  isBackup,
  isImageAvailable,
  isServerRunning,
  isServerStopped,
  isSnapshot,
  isSystemImage,
} from "@nilovonjs/hcloud-js";

const running = (await client.servers.listAll()).filter(isServerRunning);
const snapshots = (await client.images.listAll()).filter(isSnapshot);

if (isActionFailed(action)) {
  console.error(action.error.message); // `error` is non-null here
}
```

## Zod schemas

All Zod schemas the SDK validates with are exported, e.g. to validate webhook
payloads, cached data or configuration files:

```typescript
import {
  createServerRequestSchema,
  safeValidate,
  serverSchema,
  validate,
} from "@nilovonjs/hcloud-js";

// Throws a HCloudValidationError
const server = validate(serverSchema, JSON.parse(cached), { context: "Cached server" });

// Does not throw
const result = safeValidate(createServerRequestSchema, userInput);
if (!result.success) {
  console.error(result.error.issues);
}
```

Naming is consistent across resources:

| Pattern                                | Example                                      |
| -------------------------------------- | -------------------------------------------- |
| `<resource>Schema`                     | `serverSchema`, `volumeSchema`, `zoneSchema` |
| `list<Resources>ResponseSchema`        | `listServersResponseSchema`                  |
| `create<Resource>RequestSchema`        | `createServerRequestSchema`                  |
| `actionSchema`, `actionResponseSchema` | Shared by all action endpoints               |

Types follow the same idea: `Server`, `ListServersParams`, `CreateServerParams`,
`CreateServerResponse`, ...

## Building your own resource clients

The base classes used by the SDK are exported. They give custom clients the
same validation, pagination and request options:

```typescript
import { NamedResource, path, type PageParams, type RequestOptions } from "@nilovonjs/hcloud-js";
import { z } from "zod";

const widgetSchema = z.object({ id: z.number(), name: z.string() });
const listSchema = z.object({ widgets: z.array(widgetSchema) });
type Widget = z.infer<typeof widgetSchema>;

class WidgetsClient extends NamedResource<Widget, PageParams & { name?: string }, "widgets"> {
  protected readonly itemsKey = "widgets";

  list(params?: PageParams & { name?: string }, options?: RequestOptions) {
    return this._get("/widgets", listSchema, params, options);
  }

  get(id: number, options?: RequestOptions) {
    return this._get(path`/widgets/${id}`, z.object({ widget: widgetSchema }), undefined, options);
  }
}

const widgets = new WidgetsClient(client);
await widgets.listAll();
```

## Deprecated helpers

These v1 functions still work but are superseded by client methods:

| Deprecated                               | Use instead                            |
| ---------------------------------------- | -------------------------------------- |
| `pollAction(client, id)`                 | `client.actions.waitFor(id)`           |
| `pollActions(client, ids)`               | `client.actions.waitForAll(ids)`       |
| `createAndWaitForServer(client, params)` | `client.servers.createAndWait(params)` |
| `findServerByName(client, name)`         | `client.servers.getByName(name)`       |
| `findImageByName(client, name)`          | `client.images.getByName(name)`        |
| `findFloatingIPByIP(client, ip)`         | `client.floatingIPs.getByIP(ip)`       |
