## Install the package

```bash
npm install @nilovonjs/hcloud-js
# or
pnpm add @nilovonjs/hcloud-js
# or
yarn add @nilovonjs/hcloud-js
# or
bun add @nilovonjs/hcloud-js
```

The package ships ESM and CommonJS builds with type declarations. Its only
dependency is [Zod](https://zod.dev).

## Requirements

| Runtime                  | Version                                     |
| ------------------------ | ------------------------------------------- |
| Node.js                  | 20 or later                                 |
| Bun                      | 1.0 or later                                |
| Deno                     | 1.40 or later                               |
| Browsers / edge runtimes | Anything with `fetch` and `AbortController` |
| TypeScript (optional)    | 5.0 or later                                |

No polyfills are needed: the SDK only uses web standard APIs (`fetch`,
`Headers`, `URL`, `AbortController`).

## Create an API token

1. Open the [Hetzner Console](https://console.hetzner.cloud/) and select your project.
2. Go to **Security > API tokens** and generate a token. Choose _Read & Write_
   if you want to create or change resources.
3. Store the token as an environment variable:

```bash
export HCLOUD_TOKEN="your-api-token"
```

The client picks up `HCLOUD_TOKEN` automatically:

```typescript
import { HCloudClient } from "@nilovonjs/hcloud-js";

const client = new HCloudClient();
```

You can also pass it explicitly:

```typescript
const client = new HCloudClient({ token: "your-api-token" });
// or, as a shorthand
const client = new HCloudClient("your-api-token");
```

<Callout type="warn">
  Never commit API tokens and never ship them to browsers. A token grants full access to the project
  it belongs to.
</Callout>

## CommonJS

```javascript
const { HCloudClient } = require("@nilovonjs/hcloud-js");
```
