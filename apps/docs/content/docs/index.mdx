`@nilovonjs/hcloud-js` is a fully typed TypeScript SDK for the
[Hetzner Cloud API](https://docs.hetzner.cloud/reference/cloud). It covers every
resource of the Cloud API plus Storage Boxes, and takes care of the tedious
parts: pagination, waiting for actions, retries, rate limits and error handling.

## Features

- **Complete** - servers, networks, load balancers, firewalls, volumes, DNS zones, storage boxes and more
- **Fully typed** - request parameters and responses, inferred from Zod schemas
- **Auto-pagination** - `listAll()` and `for await ... of iterate()` on every list endpoint
- **Action waiting** - `client.actions.waitFor(...)` with batched polling and backoff
- **Resilient** - automatic retries with exponential backoff, `Retry-After` and rate limit awareness
- **Typed errors** - `HCloudNotFoundError`, `HCloudRateLimitError`, `HCloudActionError`, ...
- **Cancellable** - `AbortSignal` and per-request timeouts on every call
- **Observable** - request/response/retry hooks and a debug logger
- **Runs everywhere** - Node.js 20+, Bun, Deno, browsers and edge runtimes; ESM and CommonJS

## Quick example

```typescript
import { HCloudClient } from "@nilovonjs/hcloud-js";

// Reads the token from the HCLOUD_TOKEN environment variable
const client = new HCloudClient();

// Create a server and wait until it is ready
const { server } = await client.servers.createAndWait({
  name: "web-1",
  server_type: "cx22",
  image: "ubuntu-24.04",
  location: "nbg1",
});
console.log(server.public_net.ipv4?.ip);

// Iterate over all servers, page by page
for await (const s of client.servers.iterate({ label_selector: "env=production" })) {
  console.log(s.name, s.status);
}

// Every mutating call returns an action you can wait for
await client.actions.waitFor(await client.servers.reboot(server.id));
```
