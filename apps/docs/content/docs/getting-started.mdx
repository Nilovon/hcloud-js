## Create a client

```typescript
import { HCloudClient } from "@nilovonjs/hcloud-js";

const client = new HCloudClient(); // token from HCLOUD_TOKEN
```

Every API resource has its own sub-client: `client.servers`, `client.networks`,
`client.firewalls`, `client.dns`, `client.storageBoxes` and so on. See the
[API reference](/docs/api) for the full list.

## Read resources

Methods mirror the REST API and return the API's response envelope:

```typescript
const { servers, meta } = await client.servers.list({
  status: ["running"],
  label_selector: "env=production",
  sort: "name:asc",
});

const { server } = await client.servers.get(42);
```

On top of that, every listable resource has convenience helpers that return
plain items:

```typescript
// All pages at once
const allServers = await client.servers.listAll();

// Lazily, page by page
for await (const server of client.servers.iterate()) {
  console.log(server.name);
}

// Lookup by name: the item or undefined
const web = await client.servers.getByName("web-1");

// First match
const newestSnapshot = await client.images.first({ type: "snapshot", sort: "created:desc" });
```

More in [Pagination](/docs/pagination).

## Create and change resources

Request parameters are fully typed and validated before the request is sent:

```typescript
const { ssh_key } = await client.sshKeys.create({
  name: "laptop",
  public_key: "ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAA...",
});

const { server, root_password } = await client.servers.create({
  name: "web-1",
  server_type: "cx22",
  image: "ubuntu-24.04",
  location: "nbg1",
  ssh_keys: [ssh_key.id],
  labels: { env: "production" },
});
```

## Wait for actions

Most changes in the Hetzner Cloud are asynchronous: the API answers immediately
with an **action** that is still running. Pass the response to `waitFor()` to
block until it has finished:

```typescript
await client.actions.waitFor(await client.servers.powerOff(server.id));

// Responses with several actions (action + next_actions) work as well
const created = await client.servers.create({ name: "web-2", server_type: "cx22", image: "ubuntu-24.04" });
await client.actions.waitForAll(created);

// Or in one step
const { server: ready } = await client.servers.createAndWait({
  name: "web-3",
  server_type: "cx22",
  image: "ubuntu-24.04",
});
```

More in [Waiting for Actions](/docs/actions).

## Handle errors

All errors extend `HCloudError`. Specific subclasses tell you what went wrong:

```typescript
import { HCloudNotFoundError, HCloudRateLimitError } from "@nilovonjs/hcloud-js";

try {
  await client.servers.get(1);
} catch (error) {
  if (error instanceof HCloudNotFoundError) {
    console.log("No such server");
  } else if (error instanceof HCloudRateLimitError) {
    console.log(`Slow down, retry in ${error.retryAfter}s`);
  } else {
    throw error;
  }
}
```

Transient failures (rate limits, conflicts, gateway errors) are retried
automatically. More in [Error Handling](/docs/error-handling).

## Cancel and time out

Every method takes request options as its last argument:

```typescript
const controller = new AbortController();

const promise = client.servers.listAll({}, { signal: controller.signal, timeout: 10_000 });
controller.abort();
```
